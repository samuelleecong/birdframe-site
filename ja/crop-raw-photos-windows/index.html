WindowsでRAWの野鳥写真を開く・一括トリミングする方法

撮影から戻ってフォルダを開くと、RAWファイルのサムネイルが出ないことがあります。まずWindowsでRAWが開けるようにしましょう。鳥を一枚ずつ探して切り出す手間は、一括処理で減らせます。

まず確認すること　エクスプローラーでRAWのサムネイルが出なければ、Microsoftの無料のRaw 画像拡張機能をインストールします。撮影した機種のRAWファイルが1枚開けたら、フォルダごとの処理に進みます。

1. エクスプローラーでRAWを確認する

  1. Microsoft Storeで「Raw 画像拡張機能」を入手します。Windows 10ではバージョン1903以降が必要です。
  2. フォルダを開き直し、サムネイルが出るか確認します。キヤノンのCR3、ニコンのNEF、ソニーのARWなどは、拡張子が同じでも機種によって対応状況が異なります。
  3. 開けない場合は、拡張機能を更新し、LibRawの対応機種一覧を確認します。急ぐときは、カメラが同時に記録したJPEGや、普段のRAW現像ソフトから書き出したJPEGを使えます。

2. 1枚だけなら「フォト」で切り出す

画像を開き、「画像の編集」（Ctrl + E）からトリミングします。ポートレートなら鳥の視線の先、環境も見せたいなら枝や水面との位置関係を残すと、同じ写真でも意図が伝わりやすくなります。Microsoftの編集手順

3. 野鳥写真が何千枚もあるなら、フォルダごと切り出す

BirdFrameは小さく写った鳥や枝に隠れた鳥を探し、フォルダの写真を一度にトリミングします。元のフルサイズ画像から切り出して、新しいJPEGとして保存します。

  1. 撮影したフォルダを選びます。同じ名前のRAWとJPEGのペアは1枚として数えます。
  2. プレビューで構図を比べます。Tightは鳥を大きく見せたいとき、Wideは周囲の環境を残したいとき、Balancedはその中間です。
  3. すべての切り出し画像を保存するには、結果画面で Crops を選び、Export Crops から別のフォルダにJPEGを書き出します。Moments では、選んだ写真だけを書き出せます。元のRAWファイルはそのまま残ります。

次の撮影フォルダで試す

Windows 10・11対応。1回50枚まで、何回でも無料です。それ以上の枚数を一度に処理する場合は買い切りで解除できます。アプリの画面は英語です。
