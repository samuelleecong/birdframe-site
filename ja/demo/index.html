    構図

      Mac・Windows でフォルダごと一括トリミング

      何千枚でも、元のフル解像度の写真から一度に切り出せます。フォルダから切り出した画像は新しいファイルに保存します。Mac では Apple の「写真」のアルバムに、元に戻せる編集として保存することもできます。

      Mac App Store で入手 Microsoft Store で入手

      どちらの版も1回50枚まで無料です。買い切りで、さらに多くの写真を一度に処理できます。macOS 15 以降、Windows 10・11 に対応。アプリの画面は英語です。

      よくある質問

      写真はアップロードされますか？

      いいえ。すべてお使いの端末の中で行います。Cookie もトラッキングも使いません。

      どんな写真に対応していますか？

      JPEG、PNG、WebP に対応しています。HEIC は Safari で開けます。カメラの RAW ファイルは、先に JPEG で書き出してください（Mac 版の BirdFrame は、フォルダの RAW ファイルをそのまま読み込めます）。

      デスクトップ版の BirdFrame とどう違いますか？

      デモでは1枚ずつ試せて、ダウンロードできる画像は最大 1,000 px です。デスクトップ版では、フォルダ全体を元のフル解像度の写真から一括でトリミングできます。

      Windows でも使えますか？

      このページは Windows でも、最新の Chrome、Edge、Firefox などのブラウザで使えます。BirdFrame のアプリには Mac 版と Windows 版があり、Windows 版は Microsoft Store で入手できます。
