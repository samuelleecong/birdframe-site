BirdFrame · Windows

Windowsで野鳥写真を一括トリミングする方法

連写した写真を一枚ずつ開かなくても、フォルダを選ぶだけで、BirdFrameが小さく写った鳥や枝に隠れた鳥を見つけます。数千枚の写真をまとめて処理し、フルサイズの元画像から一羽ずつ切り出せます。

Windows 10・11対応。1回50枚まで無料で、何回でも試せます。アプリの画面は英語です。以下の太字は、画面に出るボタンや項目の名前です。

Microsoft Storeで入手

1. サンプル写真を展開する

サンプル写真5枚をダウンロード（ZIP・約1.9 MB）。エクスプローラーでZIPを右クリックして「すべて展開」を選びます。展開先にある Photos フォルダを使います。

2. フォルダと構図を選ぶ

BirdFrameの Choose Folder から Photos を選びます。まず Balanced を選んで Crop Photos を押します。鳥を大きく見せたいときは Tight、枝や背景を広めに残したいときは Wide が向いています。

3. 結果を確認してJPEGに書き出す

結果画面で Moments から Crops に切り替えます。写真を開いて Crop と Original を切り替えると、切り出しと元画像を見比べられます。すべての切り出し画像を保存するには、Crops の Export Crops を選び、保存先フォルダを指定します。元のファイルはそのまま残ります。

自分の撮影フォルダで試す

JPEGのフォルダはそのまま選べます。カメラのRAWを使う場合は、まずエクスプローラーで一枚開けるか確認してください。開けない場合は、WindowsでRAW写真を開く手順を参照してください。

インストールの前に写真一枚で構図を試すなら、無料のブラウザー版も使えます。
