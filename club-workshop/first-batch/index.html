BirdFrame’s recorded bird photography workshop

Your first batch of bird crops

Try five photos on Mac or Windows. BirdFrame finds the birds and crops a batch from the full-size originals, so you can compare framings without cropping each photo by hand.

Download five photos · 1.9 MB Mac App Store Microsoft Store

On a PC, watch the 42-second Windows walkthrough before trying the sample.

  1. Open the sample folder

    Get BirdFrame and the five photos using the address below. On Mac, double-click the ZIP. On Windows, right-click it and choose Extract All. In BirdFrame, click Choose Folder and select the extracted Photos folder.

  2. Start with Balanced

    In Crop Settings, select Balanced, then click Crop Photos. On Windows, select Crops in Results first. Open the spruce result and compare the crop with the original. Look for the bird at the top and the one among the branches.

  3. Compare with Wide

    For a side-by-side comparison, save the Balanced run using the step below. Then select Wide in Crop Settings and click Crop Photos Again. Does the extra space make the setting easier to read?

  4. Save your crops

    On Windows, select Crops to export every crop. On either platform, click Export Crops and choose a folder. Crop files are separate JPEGs. Save the Wide crops to a different folder if you saved the Balanced run.

Try your own photos next. Pick one small folder from a recent outing. Compare the crops before deciding which frames to share or print.
