Open and crop RAW bird photos on Windows

A fresh Windows PC often shows camera RAW files as blank icons: no thumbnails in File Explorer, and nothing in Photos. Microsoft's free Raw Image Extension fixes that in a minute. Cropping a few thousand RAW frames from a trip is the slower part, and that's where a batch tool earns its keep.

Short answer: install Microsoft's free Raw Image Extension from the Microsoft Store. It adds thumbnails and metadata for RAW files in File Explorer and opens them in Photos, including Canon CR3. Photos then crops one picture at a time. For bird photos, BirdFrame reads a whole folder of CR2, CR3, NEF, ARW, RAF, ORF, RW2 or DNG files, finds the birds and saves a JPEG crop of each one in one go, cut from the full-size original. Your RAW files never change. BirdFrame for Windows is coming soon.

On a Mac? See how to crop RAW bird photos on a Mac.

Step 1: let Windows open your RAW files

Windows reads camera RAW through an extension from Microsoft, not through Photos itself. Many Windows 11 PCs already have it. If File Explorer shows your RAW files as plain icons, install it.

  1. Open the Microsoft Store and search for Raw Image Extension, or go straight to its Store page. It's published by Microsoft and it's free.
  2. Install it. It isn't an app you open: it works inside File Explorer and Photos.
  3. Open a folder of RAW files. In Microsoft's words, you can now "view thumbnails and metadata of supported raw file formats right in Windows File Explorer or view images in the Photos app."

What Microsoft's listing says about formats:

  • CR3 works. The current version "includes support for CR3 files", the RAW format of Canon's newer cameras.
  • Most cameras work. It "supports a long list of cameras", based on the open-source LibRaw project; check yours on LibRaw's supported cameras list.
  • A few formats don't. The listing names .GPR as not supported.
  • It needs Windows 10 version 1903 or later, which any up-to-date Windows 10 or Windows 11 PC meets.

Step 2: crop one RAW photo

With the extension installed, open a RAW file in Photos, select Edit image (Ctrl + E) and crop it by hand or to a preset aspect ratio (Microsoft Support: Edit photos and videos in Windows). For careful work on a keeper, your RAW editor does the same with more control. Both are one photo at a time: fine for the best ten shots of the day, slow for the other two thousand.

Step 3: crop a whole folder of RAW bird photos

A morning at a wetland can leave you with hundreds of frames, and a week-long trip with thousands. In most of them the bird is a small shape, somewhere different in every frame, so a batch tool that pastes one fixed box onto every photo cuts it off. BirdFrame looks at each photo instead: it finds every bird, including small, distant and half-hidden ones, and crops around each one, a whole folder in one go. No cropping by hand.

  1. Choose the folder. BirdFrame reads the formats in the table below, plus JPEG, PNG, TIFF and HEIC, in the same folder. Subfolders are included, and a RAW+JPEG pair counts as one photo.
  2. Pick a framing. Preview Tight, Balanced or Wide on your own photos and choose a square or rectangular shape.
  3. Let it find the birds. A burst taken seconds apart becomes one moment, a single card showing its clearest bird, so it's quick to see what you got.
  4. Export Crops. Every bird is saved as a new full-resolution JPEG in a folder you choose. Export for iNaturalist saves tight crops named by date.

RAW files need Microsoft's free Raw Image Extension from Step 1. HEIC photos, such as those from an iPhone, need Microsoft's HEIF and HEVC Video Extensions from the Microsoft Store; the HEVC one usually costs US$0.99. JPEG, PNG and TIFF work straight away.

Full resolution, nothing generated

Each crop is cut from the full-size original. Nothing is downscaled, and nothing is generated or added to your picture, so a crop holds all the detail the frame had around the bird. Crops keep the photo's date, camera and location; turn location off in Settings to protect a nest site. Finding and cropping happens on your PC, and your photos aren't uploaded.

What to check in the crops

  • They're JPEGs, not RAW files. A crop is a finished picture, ready to share, upload to eBird or iNaturalist, or print. Keep the RAW for heavy editing; BirdFrame doesn't edit RAW files.
  • Your edits from other software aren't in them. BirdFrame works from the files in the folder. If you want your edits in the crops, export the edited keepers as full-size JPEGs first, then crop that folder.
  • The size is what the bird gave you. A distant bird gives a small crop. Right-click a crop in File Explorer and open Properties, then Details, to see its size in pixels, and compare it with what you need (how many pixels a print or a screen needs).
  • Files that don't open. If a RAW file shows no thumbnail in File Explorer after installing the extension, check that your camera is on LibRaw's list, or shoot RAW+JPEG.

Questions

How do I open RAW files on Windows 11?

Install Microsoft's free Raw Image Extension from the Microsoft Store. Its listing says it lets you "view thumbnails and metadata of supported raw file formats right in Windows File Explorer or view images in the Photos app." It needs Windows 10 version 1903 or later.

Does the Raw Image Extension open Canon CR3 files?

Yes. Microsoft's listing says the current version "includes support for CR3 files". For a particular camera, its listing points to LibRaw's list of supported cameras.

Can BirdFrame edit RAW files?

No. It reads them and saves a full-resolution JPEG crop of each bird it finds. Your RAW files never change, so do your RAW editing in your usual editor.

Which RAW formats does BirdFrame for Windows read?

Canon CR2 and CR3, Nikon NEF, Sony ARW, Fujifilm RAF, OM System and Olympus ORF, Panasonic RW2, and DNG, using Microsoft's free Raw Image Extension. A RAW+JPEG pair counts as one photo.
