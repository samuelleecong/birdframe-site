      常見問題

      照片會上傳嗎？

      不會。所有處理都在您的裝置上進行，也不使用 Cookie 或任何追蹤。

      支援哪些照片格式？

      支援 JPEG、PNG、WebP。HEIC 可在 Safari 開啟。相機的 RAW 檔請先匯出成 JPEG（Mac 版 BirdFrame 可以直接讀取資料夾裡的 RAW 檔）。

      和 Mac 版 BirdFrame 有什麼不同？

      這個網頁一次處理一張照片，可下載的圖片最大為 1,000 px。Mac 版能一次處理 Apple「照片」App 的整本相簿或整個資料夾，幾千張照片裡的鳥都會自動裁切，不用手動處理。每張裁切都取自原始的完整解析度照片（不縮小、不生成）。每次最多 50 張免費。

      Windows 也能用嗎？

      這個網頁在 Windows 上也能用，請使用最新版的 Chrome、Edge 或 Firefox 等瀏覽器。BirdFrame App 目前只有 Mac 版，Windows 版正在準備中。上架時通知我
